# PPC 首次发布范围说明

整理日期：2026-10-21。来源：当前 PPC 工作区；本地参考提交为 ee3c5c33，同时逐文件复制当前磁盘内容，不覆盖原工程修改。用户随后补全本副本 SD 卡目录并明确同意上传，该目录作为本次完整 SD 资源包的来源。

## 保留内容

- Core、Drivers、lvgl、lvgl_GUI、Utilities 中的源码与现有依赖。
- Keil 工程、启动汇编、RTE 组件头文件、自定义 scatter 链接脚本及 CubeMX 配置。
- 主机测试源码、验证脚本、字体/图像/视频转换工具源码及其实际需要的字体源文件。Tools/c_files 用于字体再生成及真实中文 LVGL 回归，保留。
- 功能使用、驱动系统逻辑、IO、内存、CubeMX 恢复说明、覆盖恢复文件、原理图和稳定版记录。
- SD 卡 SYSTEM/FONT、SYSTEM/IMG 和 PICTURE 中的字体、壁纸及界面图标资源，排除 Windows 缩略图缓存。
- 当前重编译的 HEX、SHA256、构建/回归日志；此前 2026-10-20 稳定版归档按原始字节保留。

## 不进入发布的内容

- 原 .git 历史、待移植功能文件、superpowers 计划和设计草稿、debug_state.md、阶段进度/暂存/过程调试记录。
- node_modules、Python 缓存、tmp、IDE 个人配置、编译对象/列表/MAP/AXF/备份以及可重新生成的中间文件。
- Tools 下的视频转换输入输出不进入发布。用户在本副本 SD 卡目录中补全的音乐、视频、ROM、NAND 测试文件和示波器记录完整收入 Release 的 SD-card-resources-20261021.zip；这些大资源不作为普通 Git 对象提交。
- 串口助手可执行程序及重复的 SD 卡 Note 文档副本。

排除规则仅作用于本次源码提交，不删除原工作区或用户补全的文件。SD 卡资源包保持用户给出的目录和文件原始字节；ZIP 内直接是 SD 卡根目录内容。

## 校验边界

- Keil 工程共有 1367 项文件引用，发布副本没有缺失的编译源码，也没有指向副本目录外的源码依赖。
- 原工程本就缺失 7 项非编译 README/LICENSE 引用，主要为可选 LVGL 子库；本次未伪造或补写第三方许可证。这不阻止当前目标构建，但以后开放分发第三方组件前应补齐其上游许可资料。
- 编译与主机回归不等于板端验收。本次不自动烧录；用户于2026-10-21明确同意上传。

## 发布方式

源码以本副本干净快照提交至私有仓库 main，标签为 ppc-2026-10-21。Release 提供 HEX、完整 SD 资源包及 SHA256 校验文件；固件仍与2026-10-20稳定归档字节一致。原工作区 Git 历史、分支及本地改动均保留。
