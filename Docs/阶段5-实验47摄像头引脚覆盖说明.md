# 阶段5：实验47摄像头引脚覆盖说明

## 真值来源

当前阿波罗 V2 摄像头引脚以用户提供的官方“实验47 照相机实验”源码和 `readme.txt` 为准。不同底板的 `Smart_Desk_Lamp` 工程不再作为本工程的引脚依据。

## 当前引脚

| 摄像头信号 | STM32 引脚或外设 |
|---|---|
| SCCB SCL | PB4 |
| SCCB SDA | PB3 |
| RESET | PA15 |
| PWDN | PCF8574 P2 |
| D0-D7 | PC6、PC7、PC8、PC9、PC11、PD3、PB8、PB9 |
| VSYNC | PB7 |
| HREF | PH8 |
| PCLK | PA6 |
| XCLK | PA8（官方实验接线表列出，但可运行源码未配置输出） |

## 已直接修改的 CubeMX 生成源码

由于当前阶段要求快速验证硬件，以下文件已直接修改，未修改 `.ioc`：

- `Core/Inc/main.h`：纠正 SCCB 宏为 SCL=PB4、SDA=PB3，删除错误的 `DCMI_PWDN_Pin/Port` 定义。
- `Core/Src/gpio.c`：删除 PD7 摄像头 PWDN 初始化；PB4 配置为推挽上拉，PB3 配置为开漏上拉。
- `Core/Peripheral/Src/ov5640_service.c`：PWDN 只通过 PCF8574 P2 控制，并采用实验47的 RESET/PWDN/SCCB 上电时序。

## 重新生成 CubeMX 代码后的恢复项

CubeMX 重新生成后，上述手工修改可能被覆盖。恢复顺序如下：

1. 在 `main.h` 恢复 SCCB SCL=PB4、SDA=PB3，并删除 PD7 摄像头 PWDN 宏。
2. 在 `gpio.c` 保持 PB4 推挽上拉、PB3 开漏上拉，且不初始化 PD7 为摄像头 PWDN。
3. 在 `ov5640_service.c` 保持 PWDN 只调用 PCF8574 P2，不重新加入 PD7 写入。
4. 重新运行 `test_camera_keil_project_contract`、`test_ov5640_sccb` 和 `test_camera_resource_service`。

本说明不改变 SD/DCMI 的复用策略，也不要求当前阶段占用 PA8；PA8 继续保留给红外输入捕获。
