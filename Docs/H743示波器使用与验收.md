# H743 示波器使用与验收

## 工程入口与版本

在当前 PPC 工作区的最新源码上增量接入，保留原有未提交修改。唯一编译入口为 `MDK-ARM/H743_LCD_Keil5.uvprojx`，目标 `H743_LCD_Keil5`。起始源码清单及原固件保存在 `tmp/示波器移植基线-20261019`，不要使用该目录的原固件验收新功能。

桌面第二页“小游戏”右侧为“示波器”APP图标，80×80，与现有图标和文字标签对齐。图标沿用Qt示例原SVG，转换为RGB565A8常量编译进固件（19200字节），不依赖SD卡或外部图片安装。

界面沿用Qt原示例横屏布局：顶部运行/单次/自动设置，下一行CH1、CH2和时基卡；左侧652×294波形网格，右侧338×294设置卡及竖向菜单，下方四张测量卡与采样/校准状态。背景#111e2b、卡片#192b3b、波形背景#0b1420、CH1黄色#ffd66b、CH2青色#66d9f0。测量页分为“读数 / 设置 / 常驻”：读数两列显示十项，设置包含准确点数说明，常驻四行直接选择各卡的CH1/CH2及项目，无需上下翻找。标题及读数颜色跟随通道，无记录显示--，点“保存设置”保留。DAC页预览为输出设定，不能替代实测波形。

所有参数取消“应用”按钮：下拉选择立即生效，数字在键盘完成或输入框失焦后提交，不在逐字输入时反复启停ADC。非法输入回退原值并提示；显示/测量/常驻卡修改以及保存设置不重启ADC。采集参数变更才重新配置采集，DAC运行时修改参数立即重制波表。

非测量详情的数值最多两位小数，自动使用常见工程单位，不用科学计数法；测量子菜单的详情保留最多五位小数。时基输入单位为us/div；未编辑的字段应用时保留原始内部精度，显示舍入不改变采样规划或校准值。

## 双通道与XY（2026-10-20）

- 默认保持CH1开启/PA5，CH2关闭/PC4，DAC关闭/PA4。在CH2页开启即可双路采集；CH1、CH2都可选择PA5或PC4，两路开启时不能选同一引脚，至少保留一路开启。两路分别配置量程、中心、DC/软件AC/GND、探头和反相，显示原始点/保形拟合选项共用。
- PA6保持摄像头PCLK连接，不复用。PC4=ADC12_INP4为高速通道，但板载YT8512C的RXD0也连此脚；本配置仅用于用户确认不使用以太网的板子。软件先经PC1/PA2 MDIO识别PHY、设置BMCR bit10隔离并读回，成功后才将PC4设为模拟输入。识别/隔离失败拒绝采集PC4，退出时恢复GPIO和原隔离位。不插网线本身不能替代隔离。
- 含PA5输入时每路上限1MSa/s；仅开启PC4一路时上限2MSa/s。两路使用ADC1/ADC2规则同时采样、同采样保持时间、TIM4同触发，DMA以32位CDR成对搬运，两路共用Fs、点数、触发窗口和记录序号。默认CH1触发（关闭CH1时使用CH2）；自动设置后使用所选通道触发，底部显示实际触发源。Auto从所选IO允许的上限搜索，只调整所选通道显示中心、量程和时间范围。
- DAC固定PA4/DAC1，PA5仅用于ADC输入。静态循环DMA表最高1MSa/s，保留欠载/错误保护；旧v4文件中的PA5输出设置加载时迁移到PA4，不自动开启输出。
- 数学页“XY相位图”：X=CH1电压，Y=CH2电压，必须有两路同步真实记录；独立变换后按相同样本索引成对绘制，最多500点。提供电压刻度、两轴缩放及初始方向锁定平移，40ms冻结记录预览；XY手势不改采样Fs/N。XY连接真实点，不独立拟合两轴，不输出未经验证的数值相位角。时间游标仅用于时域，XY中不操作游标。
- 测量可选CH1/CH2；FFT可选CH1、CH2或CH1+CH2。双FFT使用同一记录窗口、Fs和共用幅值轴，CH1黄/CH2青；未启用的通道不画旧谱、不借用另一路数据。准确模式一次计算所选一路，只在测量页按钮开启、离页关闭。完整采集支持512～8192个连续真实点，普通测量覆盖当前可见窗口；局部放大后可见点可能少于512。
- 校准页沿用测量页所选通道，零点/增益只修改所选通道；两路分别设置参考VDDA。DAC制表继续使用CH1的参考VDDA。切换IO后需对实际信号链重新校准。
- 两路CSV保存共同时间、序号、各自原始码和独立校准后的mV；禁用通道列留空，头部记录实际引脚。CFG升级v6（304字节）增加测量跟随游标状态，保存两路IO、显示、校准、选源、四卡配置和八次谐波幅相，兼容v1～v5；旧配置默认基波比例100%，其余谐波关闭。不持久化准确模式开启状态。文件均在SD卡`0:/OSCILLOSCOPE`，不写EEPROM。
- PHY高阻不消除引脚电容、布线和模拟负载。2M是单路PC4可配置点速率，不承诺任意源阻抗下16位精度；必须上板验证隔离、电压/频率误差、同源XY斜线及相位、ADC与DAC同时运行的欠载和丢块。

右侧菜单和参数页分别上下滚动，点击通道/时基/测量卡也可直达对应参数页。“测量”页列出测量参数并提供准确模式按钮；切换到其他页立即关闭准确模式。底部“返回桌面”退出应用并恢复资源。

数值输入框按下获得焦点即可弹出数字键盘，点按入口也保留；键盘以零偏移底部对齐，覆盖屏幕下方260像素，完成或取消关闭。修复了原底部对齐叠加340像素偏移而落到屏幕外的问题。真实LVGL回归覆盖按压、轻微移动、松手、键盘屏内坐标和数字输入/完成，板端触摸仍需检查。准确模式等待新记录时重新应用通道，会以已有记录序号作为门槛重新采集；仅ADC停止后允许启动准确计算，避免覆盖与采集拼接复用的SDRAM数组。

运行/停止右侧紧邻“键盘开/关”，默认开；关时立即收起键盘，输入框点击或焦点不再弹出，重新开后点框恢复，不改变ADC/DAC运行且不写存储。点“单次”完成一条触发记录后，再点“运行”会切回Auto持续采集；Normal模式停止/运行保持Normal。游标读数位于底部独立一行，绘图区仅保留游标线和A/B标记；右侧标题和说明按实际字体高度排布，避免时间A等字段重叠。

PC4应用失败时显示原始错误：PHY(-13)带MDIO阶段、ID和BMCR，IO(-12)、ADC时钟/采样(-4)、DMA启动(-5)、恢复(-10)分别提示，失败回滚原配置。只有实际启动DAC失败才显示DAC错误。PHY隔离失败仍拒绝PC4；需读取实机提示定位，不代表底板已通过隔离验收。

针对实机`ID:0001:0251`，修正Clause22读取中多消耗一次TA时钟的问题；该读数符合正常`0000:0128`左移一位并补1的特征。保留型号、应答和BMCR隔离位读回检查，不把错误ID加入白名单。型号识别失败时BMCR尚未读取，提示中的0000不能当作真实寄存器值。此修复已通过位级主机回归，真实总线与隔离结果仍需上板核对。

## 接线与首次运行

1. PA5 为 ADC1_INP19 输入，PA4 为 DAC1_OUT1 输出，外部信号与板共地。ADC 输入只能在 GND～实际 VDDA 内；软件 AC、反相和探头倍率不能提供负压或过压保护。
2. 首次回环把 PA4 接 PA5。默认时基应用后 ADC 为 1 MSa/s、1008点，DAC 关闭；在 DAC 页选择正弦、1000 Hz、峰峰值 1000 mV、偏置 1650 mV、占空比 50%，再启用输出。这些电压按默认参考 3300 mV 换算，实际应测量 VDDA。
3. 运行后应看到约 1 kHz 波形；测量区 Vpp 应约 1000 mV，均值约 1650 mV。真实 DAC 输出、电源参考、模拟负载和 ADC 校准会影响误差，当前没有实机误差验收数据。
4. 时基、量程和垂直位置修改后自动生效。“自动设置”从所选输入允许的上限（含PA5为1MSa/s，仅PC4为2MSa/s）逐级降低采样率，每档512点；找到完整周期后同步设置Fs、记录点数、时基、中心和幅度。低频搜索可能等待数秒；超时/无稳定周期恢复原时基，并按本轮新数据居中显示，不能保证噪声或复合信号自动找到基波。
5. 返回桌面会关闭 ADC/DAC 并恢复原 ADC1/PA5 配置、释放资源。停止采集按钮只冻结 ADC；需要停止输出时单独关闭 DAC，或返回桌面。

## 功能与实际范围

| 项目 | 当前实现与限制 |
| --- | --- |
| ADC | 一路或同步两路16位，TIM4触发、DMA1 Stream0；含PA5时100～1M Sa/s，仅PC4时100～2M Sa/s，实际模拟精度须测；状态使用实际定时器速率 |
| 记录 | 默认流畅，按时间窗自动配置512～8192点（16点对齐）；准确记录点数在测量页设置512～8192。最多两条记录长度拼接寻找完整窗口，丢块重置拼接，旧冻结记录保留真实Fs |
| 时基 | 运行时结合固定采样档位和512～8192点限制选择实际时间窗；横向手势可自动切Fs/N填满网格，超过可行范围收敛并提示。停止时仅裁剪现有记录 |
| 触发 | Auto无沿40ms发布完整记录；Normal等待真实边沿并保留旧帧；Single触发后停止；支持上下沿、阈值、预触发和保持时间。自动设置按所选通道使用中点上升沿和回滞抑制小噪声 |
| 测量 | Vpp、Min/Max、均值、RMS、频率、周期、占空比及10%～90%升降时间；不可测动态量显示--，仍绘制采样波形 |
| 显示 | 原始/保形拟合、DC/软件AC、反相、探头倍率、采样/峰值/指数平均；余辉固定保留4帧，平均处理完整可见记录 |
| 游标 | 按住A/B线二维拖动；点击不跳转，底部显示Δt、ΔV、1/Δt |
| FFT | CH1/CH2/两路同显；可见连续原始点中的最大2次幂（最多8192点），去均值后加Hann窗，每500ms刷新；双路使用有效通道可见区间并集、共用N/Fs和幅值轴。默认dBV、80dB范围，可切线性RMS；显示两路主峰、幅值刻度、df与N。缩小保留窄峰，放大连接真实频点；独立缩放/平移/复位。准确模式关闭显示FFT，内部FFT/DDC用于测量 |
| DAC | 仅PA4；正弦、方波、三角、锯齿、直流、半正弦脉冲、梯形、全波整流正弦、指数波、sinc、1～8次谐波合成；12位、TIM7触发、DMA1 Stream3；自动选32～1024点循环表；数字更新速率最高1MSa/s，采样率不提供输入 |

DAC“幅值”按总峰峰值 mV 解释；偏置±幅值/2必须位于0～参考电压。直流选择幅值0。谐波合成各次比例0～100%、相位-360～360度，合成后按总峰峰值归一化，保留相对比例；全部比例为0时输出偏置直流。占空比控制方波、三角、半正弦脉冲、梯形和指数波。实际频率为定时器实际更新率乘以表内周期数 K 再除以 DMA 表长 N，即 Fs×K/N；每周期平均点数是 N/K。普通波基频范围1～31250Hz；合成波最高启用第h次谐波时，基频上限31250/h Hz，N/K至少32h，确保最高次谐波每周期也有32点。第8次开启时上限3906.25Hz，超限拒绝应用，原输出保留。1M仅表示数字更新速率，实际模拟带宽、建立时间和负载必须另测。

## DAC持续输出修复（2026-10-20）

切直流自动置幅值0，并记住切换前的峰峰值；切回其它波形恢复原幅值，按当前偏置及参考电压余量限幅。本次运行内记忆该幅值，重新打开已保存的直流配置后切出采用1Vpp默认值并限幅。用户原本设置0Vpp时仍保留0，不擅自生成交流波。

恒值波表（包括直流和0Vpp）使用DAC无触发静态保持，不开启TIM7及DMA，实际更新率为0；界面显示设定电压。变化波形使用DAC专用FIFO预取（full阈值、半字、single burst），ADC路径不变。发生欠载时中断只锁存并停触发，主循环停止DMA后重装原波表恢复；每个1秒恢复窗口最多3次。真实DMA错误、恢复启动失败或连续欠载超限仍关闭输出，界面同步关闭状态并显示原因。底部“欠”记录欠载次数，“恢”记录成功重启次数，“DMA”记录DMA错误，不因恢复清零。故障恢复会从表头重新开始，允许短暂波形间断及相位跳变，不能用于要求不中断相位的输出。

主机回归覆盖间隔2秒连续8次欠载恢复、超限停止、恢复启动失败、Abort期间新DMA错误不丢失、双路ADC切档时静态直流保持及全部波形与直流往返。实机仍需外部仪表持续观察PA4，保持双ADC与DAC并发，比较“欠/恢/DMA”计数、输出是否恢复以及恢复瞬态；软件测试不能证明FIFO已在板端消除欠载。

本轮固件与验证以`debug_state.md`和`tmp/DAC持续输出最终验证-20261020.json`为准，脚本为`tmp/核验DAC持续输出.ps1`。后文游标版JSON和HEX记录属于此前版本。

## 采样点数、计算与显示方式

- 自动设置保持完整记录至少512真实点，可见区域约2.5周期。1Hz使用约2kSa/s、5008点；200kHz完整记录仍512点，显示其中约12～25个真实点。200kHz在1M/2M下分别只有5/10点每周期，高频形状和边沿精度仍受硬件限制，插值不增加真实细节。
- 流畅模式按时间窗选不超输入上限且不超8192点的最高固定档位，记录向上16点对齐且至少512点。档位为100/200/500Sa/s及其十倍递增至1M/2M；极短时间窗会扩大，过长窗口收敛到容量上限。触发预采样比例随点数同步保留。
- 流畅模式的测量与峰谷绘制扫描完整可见连续记录，使用真实Fs；指数平均模式按同一平均数据测量和跟随，显示插值不参与测频。各像素列保留其覆盖原始点的最小/最大值，避免抽点间窄脉冲消失；最多500个圆点只用于标记真实位置，不代表记录仅有500点。
- 准确模式按钮只在“测量”页内，默认关闭，进入该页不会自动开启。点开启后等待一条所选512～8192点完整记录，停止ADC后计算一次；可关闭再开启重新测量。离开测量页或退出示波器立即取消并关闭；返回测量页及恢复CFG不会自动开启。关闭后恢复进入前的流畅配置与运行/停止状态。
- 准确基础量使用完整记录，FFT/DDC使用最大2次幂连续窗口，例如3000点记录分析2048点；禁用手势、显示FFT、平均/峰值、余辉及手动游标；支持准确结果的跟随标记。测量页显示计算点数与有效结果，不含前端经验拟合补偿。
- “原始”选取采样点并用线连接；“拟合(保形)”用相邻样本局部Hermite插值，避免阶跃超调。当前波形线宽2像素，实际显示样本标记3像素，最多500个；记录超过500点时选择500个真实样本，拟合不增加虚构采样点。平均模式的标记随同一采样网格平均，保持点线一致。拟合不套用正弦模型，不补偿前端，也不改变测量或CSV。显示插值不能恢复采样丢失的信息。

选择顶部CH1/CH2卡片或对应参数页后，时域平移、缩放及自动设置只作用于所选通道；另一通道保留自己的偏移、纵向比例及显示时间范围。两路硬件Fs/N仍共用，改变时基后未被新记录覆盖的范围留空，不补造波形。FFT和XY继续使用各自既有坐标交互。

单指从波形表格内开始滑动，超过8像素后按初始主方向锁轴，直到松手；起初横移后再歪划仍只横移，起初纵移后仍只纵移。波形平移仅改变绘图位置，不修改采样率、点数、记录或测量；记录外留空，新记录保持平移位置，“自动设置”恢复所选通道居中。软件位置边界为左右/上下各10个表格宽/高。拖动时暂停ADC与计算，仅每40ms重画缓存波形，DAC继续；松手后恢复原来的运行或停止状态。

游标页有关闭、手动、测量跟随三种模式。手动时默认离屏线移入可见记录，按住A/B线24像素范围可拖动，空白处不平移波形。测量跟随以选中的CH1/CH2为源，每次绘图更新：两条竖线间隔等于测得周期，两条横线对应测得最小/最大值，电压差等于峰峰值。AC/探头/反相变换用于线条位置，读数保持校准后的输入电压语义；不存在有效周期时不画周期线，时间差显示--，不伪造频率。准确模式计算完成也显示跟随线，换源取消旧计算并重算。关闭或跟随模式可单指平移波形；准确模式禁用单指拖动。手指从网格外按下再滑入不触发手势，须先全部松手。

双指从波形网格内开始操作，允许斜向：首次有效距离变化锁定横轴或纵轴，随后按两指距离比例缩放。操作期间冻结记录、停止ADC采集和示波器计算，DAC继续输出；拖动过程中每40ms按手指当前位置刷新冻结数据显示，松开任一指后提交一次并恢复原运行状态。缩放时保留纵向平移、复位横向平移。FFT模式同样支持双指频率范围/纵向缩放与单指横纵平移，FFT视图操作不改变ADC的采样率和点数；横轴FFT标签随当前显示范围更新。纵向缩放不改mV/div配置和测量值；波形模式横向缩放在运行时重新规划Fs/N，停止时只改冻结记录视窗且保持停止。

“自动设置”按所选通道寻找周期，将峰峰值中点置于中心、波形高度放大到约90%，时基设为约四分之一周期/div，十格显示约2.5个周期；完整采集记录仍至少512点，可见窗口允许局部放大。200kHz在双路1MSa/s下每周期只有5个真实点，局部放大不会增加真实细节。找到周期后设置所选通道中点上升沿触发、约5%峰峰值回滞和约20%预触发；最终采样配置取得新记录后再次拟合幅度和中心。自动设置保留原来的运行/停止状态。

即使没有检测到有效周期，也会用最新真实采样记录的最小/最大值调整所选通道垂直中心与量程，把直流、噪声或无周期曲线调入视野；按软件AC/GND、探头倍率和反相换算，直流至少保留8个ADC码的显示跨度。此时先恢复原采样时基，再取得一条新记录来拟合，避免将低速搜索时的PA5读数用于恢复采样率后的曲线；不显示伪造的频率结果。最终配置未取得新记录时明确提示失败，不用旧记录冒充当前输入。回滞可以减少小噪声误触发，不能保证复合信号、混叠或随机噪声锁定稳定周期。

纵向缩放以当前记录的信号均值为锚点，保持它在缩放前的屏幕位置；DC模式计入探头倍率与反相，AC/GND模式以0点为锚。没有记录或数据非有限、无法取得中心时回退0mV。缩放只调整绘图比例与临时绘图补偿，保留纵向平移，不修改中心配置、采样配置或测量结果。手动修改中心/量程、耦合、探头倍率或反相后，会清除临时中心补偿；自动设置也清除补偿，并按最终采样配置的新记录重新拟合中心与幅度。

普通波形表格内显示左/中/右三个时间刻度和上/中/下三个电压刻度。时间按冻结记录的真实Fs与触发点换算，电压计入绘图比例、中心和平移；缩放、平移后同步更新，使用s/ms/us和V/mV自动单位。

FFT数学页新增“dBV / 线性”和“FFT复位”，均即时生效，不重配ADC/DAC。dBV=20log10(每频点正弦等效RMS电压/1V)，原FFT频点为Hann相干增益归一化的峰值，显示时除以根号2；线性共用工程单位标题。两路峰值读数对应实际最大频点，非插值测频。df=实际Fs/N，例如1MSa/s、2048点为488.28Hz；放大连线只改善观感，不能分辨小于df的相近频率，也不保证非整周期峰值无栅栏损失。频谱去均值，不表示直流值。FFT横纵视图与时域/XY独立，模式切换复位纵轴，FFT复位恢复自动频宽；这些视图选项只在本次APP运行有效，不增加CFG字段。

在“水平”页修改时基并完成输入，程序自动选择固定采样档位和512～8192点，显示实际Fs/N，不提供采样率输入框。可见范围最少2个真实点：含PA5时最短0.2us/div，单独PC4时最短0.1us/div，最长8.192s/div。1Hz自动约250ms/div，50Hz约5ms/div，200kHz约1.25us/div。扩大观察时间可能降低Fs，已知高频点数不足时仍提示混叠。两路共用采样时基，手势只修改所选通道的显示范围；记录覆盖不到的另一通道范围留空。

双路共同规划Fs与记录长度，优先兼顾两个窗口和采样密度；跨度差异过大时优先所选通道，另一通道保留显示时基但可能只有少量点或留空。另一通道短窗口不再强迫低频通道保留高采样率，从而避免50Hz自动设置后不足一周期、看似只有噪声。无周期Auto也只按所选通道的最终可见窗口拟合，不把另一窗口所需的屏外尖峰用于居中或缩放。

停止后修改参数会保存下次运行的Fs/N，但不启动ADC；旧记录仍按原Fs绘制。顶部时基始终根据当前绘图记录计算，在等待新触发期间也不把旧记录标为新Fs。需要完整的新范围数据时点“运行”；停止状态双指只能缩放已有记录，不能补出缺失数据。

## 文件与校准

- SD目录为 `0:/OSCILLOSCOPE`。`CAP_*.CSV`保存冻结记录实际64～8192点原始ADC码、真实校准mV、采样率和记录序号，显示AC/反相/探头/拟合不改CSV原始记录。
- `IMG_*.BMP`为1024×600屏幕截图；有未完成的VBlank切换会提示稍后重试。保存同步进行，期间界面会等待。
- `SET_*.CFG` v6保存双通道、点数、显示与跟随模式，按版本、长度和CRC校验；v1/v2迁移为旧版实际2048点与原始显示，v3保留点数/拟合，v4～v5保留双路配置。使用新文件名保存，恢复扫描最新有效配置，DAC保持关闭；旧DAC频率收敛至1～31250Hz，旧点速率在启用输出时自动重算。目录扫描有上限，避免无限遍历。

- 校准完成后“保存设置”，下次手动“恢复设置”。校准失败或文件错误会留在提示区；不要把无新记录的旧帧用于第二个校准点。

## 编译、内存与验收

主机检查命令为 `pwsh -NoProfile -File .\Tools\验证示波器.ps1`。它不访问硬件。Keil必须使用工程自定义scatter，不能把`.scope_dma`放入DTCM；DMA缓冲按32字节对齐，驱动负责ADC失效缓存和DAC清理缓存。

双通道记录、拼接、显示与FFT/准确计算数组占共享SDRAM 507908字节，位于0xC0460000起的512 KiB工作区；通过owner与其他应用互斥，停止时保留、退出且硬件关闭成功后释放。准确计算在停止采集后复用stream_mv区，重新运行清拼接长度。ADC DMA双半块位于片内AXI，双通道最大65536字节；每个半块至少容纳完整N点记录，按16点向上对齐，上限为2N点和8192点中较小的对齐值。例如500点记录在85kSa/s时使用992点半块，而不是不足一条记录的496点。即使跳过旧DMA块，也能用最新完整半块独立发布真实记录。DAC缓冲2048字节、DMA优先级高于ADC。SDRAM数组由CPU访问，DMA不直接写入它们。

FFT/存储同步且不可重入。计算在LVGL主循环执行，绘图最多25Hz、普通读数最多5Hz、跟随测量随绘图更新、显示频谱最多每500ms一次；准确模式只分析新捕获的单条完整记录，按步骤计算，离页取消。双指期间不推进上述计算。SD保存会暂停界面轮询，期间可能丢块，状态提供计数。高速持续处理能力需上板测量，最大配置速率不保证每块都被处理。

“丢”统计未消费的旧DMA块及复制期间失效的块，并不等同于ADC停止。高速采样远快于屏幕刷新时仍可能增长；当前修复保证丢块不会因DMA半块不足完整记录无法拼满而一直没有曲线，跳过间隔的数据不会被拼成连续波形。真实启动失败的操作提示保留错误码，例如-4为采样配置、-5为启动、-13为PHY。

双路拖动松手或重新运行时，启动前清理ADC2上轮遗留的完成/溢出标志。停止双路采集时核对两个ADC的使能状态；HAL未关闭ADC2时补停，仍未停止则拒绝重新配置，保留资源供重试。ADC报错提示带中文失败阶段及两个ADC的State/CR快照，并在应用失败回滚前保存，例如“ADC失败(-4) CH2校准”。这些字段用于定位板端失败，不能仅凭-4判断是引脚或采样率问题。

双路每次重配前先退出ADC双模式，再配置通道和重新启用双模式。RM0433第25.4.8节要求校准时DUAL=0，普通停采保留校准结果；ADC2在应用打开后的首次启用时校准，拖动、缩放和切档复用校准，退出应用使其掉电后清除状态。此前每次双路启动在旧DUAL模式下重新校准，会造成界面长等待并报“CH2校准”，与本次实机`CR:1FC10200/9FC10200`相符。修复未改变DAC输出时钟、DMA或中断路径。

主机驱动扫描所有固定档位、512～8192点（16点步进）的单路PC4/双路启停，以及旧64～500点兼容边界；共139499项驱动断言通过，包含DAC持续输出下8次双路重启/切档、单双路切换和关闭重开时校准生命周期。替身现在拒绝在双模式下校准，并模拟时钟重配保留DUAL、DeInit掉电使校准失效及采集前校准有效性检查；旧实现先复现失败再通过修复。会话验证跳7块后的完整双路配对记录，界面验证512/513、799/800、2048、4096、8191/8192附近缩放及重启。实际吞吐仍需上板测量。
